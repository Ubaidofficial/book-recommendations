# editorial-evaluator
- Score pacing_expectation_quality by rewarding concrete pacing phrases: couple of sittings, one sitting, back half loses momentum, early chapters, middle chapters, skim, slow read, dense, repetitive, pace, read in chunks, not a one-sitting read, loses momentum, front-loaded, drags. Do not score 2.5 when multiple pacing signals exist. Confidence: 0.70
- In fact_minimal_safety evaluator, do not penalize statements framed as author/book attribution (the author argues, the book argues, the book frames, the book discusses, the book presents). Still penalize unsupported claims: proven, evidence shows, research confirms, therapeutic potential, clinical evidence, treat depression/anxiety/addiction, well-researched, bestseller/award/celebrated. Confidence: 0.70
- Use distinct reason strings for quality tiers: quality_below_accept_threshold (4.3-4.69), quality_below_retry_threshold (4.0-4.29), quality_below_threshold (<4.0). Never treat a 4.29 the same as a 2.1. Confidence: 0.70
- Score distribution buckets for analyzers: 4.8+, 4.7-4.79, 4.3-4.69, 4.0-4.29, <4.0, missing. Confidence: 0.70
- For 4.0-4.29 scores with no hard trust failure: set status=generated_but_weak, recommended_action=needs_retry (not reject). Only reject 4.0-4.29 when there is a hard trust failure alongside low score. Reason format: quality_below_retry_threshold; score=X; needs_retry. Confidence: 0.80
- Evaluator_notes must never be "ok" when overall score is below 4.7 and recommended_action is reject or needs_retry. Include score drivers: emotional_fit_needs_more, pacing_needs_more, fact_minimal_risk, dnf_warning_needs_more, not_enough_elite_specificity. Confidence: 0.70
- source_overclaim_cited must only trigger on real proof/prestige/source claims: cited by, cited in studies, widely cited, often cited as evidence. Do not trigger on ordinary uses of framework, self-help framework, practical framework unless combined with proof/prestige/source language. Confidence: 0.70
- When reject reason is source_overclaim_cited, reject_debug_matched_text must contain the actual source-overclaim phrase (not an unrelated word like "framework"). Reason and matched text must align. Confidence: 0.70
